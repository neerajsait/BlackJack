# BlackJack

> A browser-based Blackjack game built with plain HTML, CSS, and JavaScript.

## Overview

Play a hand against a simple dealer. The interface tracks outcomes and applies the game flow described in the project: draw or stand, then let the dealer play.

## What’s in this repo

- Hit and stand controls
- Dealer turn and win/loss/draw tracking
- Responsive card-table styling and simple animations

## Stack

HTML, CSS, and vanilla JavaScript.

## Getting started

1. Open `index.html` in a modern browser, or serve the repository with any static web server.
2. No package installation or backend service is required.

## Notes

This is a small game implementation for learning and entertainment; it is not a wagering or gambling service.
